# Mix & Blooms — Android App (Test Build)

This page is for installing the **Mix & Blooms** Android app for testing.
**For Android phones.** Customers, Shop Owners and Florists can use the app. Shop Owners and Florists can also use the web version at https://mixblooms-ea632.web.app.

## Download

👉 **[Download page](https://charissevill.github.io/mix-and-blooms-app/)** · [All releases](https://github.com/charissevill/mix-and-blooms-app/releases/latest)

## How to install

1. **Open the latest release.** Scan the QR code, or tap the link above.
2. **Download the app.** Scroll down to **Assets** and tap **`mix-and-blooms.apk`**.
   Do **not** tap "Source code".
3. **Allow the install.** When the download finishes, tap **Open**.
   If your phone says installing is blocked, tap **Settings**, turn on **Allow from this source**, then go back.
4. **Install.** Tap **Install**. If Google Play Protect shows a warning, tap **More details → Install anyway**.
5. **Open the app.** Tap **Open**, or find **Mix & Blooms** on your home screen.

## Updating

Scan the same QR code again and install the newest file. It updates the app you already have.

## Having trouble?

| Problem | What to do |
|---|---|
| QR code won't scan | Type this link in your browser: `charissevill.github.io/mix-and-blooms-app` |
| Download stops | Check your internet and download again. |
| "Install blocked" | Allow installs from your browser (step 3). |
| "App not installed" | Make sure you downloaded the newest file. If it still fails, uninstall Mix & Blooms first, then install again. |
